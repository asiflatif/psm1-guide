# PSM I study course

A free, self-paced study course for the Professional Scrum Master I (PSM I) exam, based on the 2020 Scrum Guide and the three PSM I focus areas: understanding and applying the Scrum framework, developing people and teams, and managing products with agility.

## Features
- 27 lessons with key points, exam traps and quick checks after each lesson
- A study plan that spreads the remaining reading across the days before your exam date
- A study burndown chart: ideal pace compared with your actual progress
- A 76-question practice bank, timed at the real exam pace of 45 seconds per question
- A one-page cheat sheet
- Plan status: in progress, paused (shown as shaded days on the burndown), completed or cancelled, with a history of past plans
- Appearance settings: system, light or dark mode, and four soft accent colours (sage, sky, sand, lavender)
- Small touches: a study streak, a reading progress bar, an animated burndown and confetti for milestones. Animations are turned off when the system's reduced-motion setting is on

## Progress storage
There are no accounts. Progress is stored in your browser's `localStorage`, so it stays on that one browser and device. Use **Export progress** and **Import progress** on the Study plan page to back it up or move it to another device.

## Run it
Open `index.html` in a browser. It's a single file with no build step.

## Publish with GitHub Pages
1. Push `index.html` and this README to a public repository.
2. Go to **Settings → Pages**, set the source to the `main` branch and the root folder, and save.
3. The site will be published at `https://<username>.github.io/<repo>/`.
